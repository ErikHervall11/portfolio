03 // Previous quest

DreamWorld

An infinite open-world sandbox MMO, built in Unreal Engine 5.

DreamWorld set out to be one enormous shared world: an MMORPG with no edge to the map, where building, inventory and world interaction all had to hold up across a networked sandbox.

I worked on it as a gameplay developer. The project has since gone into hibernation, but it's where I learned the most about what it takes to build a game at that scale.

DreamWorld on Steam ↗

XP gained

  • Gameplay systems Building, world interactions, inventory and asset placement in a large multiplayer C++ and Blueprint codebase.
  • UI and onboarding Menus, tutorial flow and player feedback built with Widget Blueprints.
  • Profiling Hunting GPU and CPU bottlenecks with Unreal's tools and RenderDoc.
  • Scalability Tuning cvars, shadows, LODs, Nanite, foliage and texture streaming.
  • Huge worlds World generation and streaming for an open world with no fixed size.
  • Listening to players Using playtests and community feedback to decide what to fix next.
